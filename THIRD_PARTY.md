# Third-party assets

The current core browser runtime is original project code and uses native browser APIs. No jQuery, Bootstrap, Font Awesome, or AdminLTE distribution is bundled in this repository.

Applications using LTEAdminUI must supply their own compatible AdminLTE 3 browser assets and retain the licenses/notices for every package they distribute. The library's MIT license does not replace those packages' licenses.

The preserved legacy CyQueryUI2 entry references external plugins which are not included. It is historical source and cannot run independently with those dependencies missing.

CI references GitHub Actions and setup tools under their own terms. They are not copied into this package.

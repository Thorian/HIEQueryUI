# Changelog

## 0.2.0-rc.1

- Fresh/restored widget registration and deduplicated refresh queues.
- Container updates, cycle checks, escaped attributes, and explicit trusted markup.
- Registered-event-only POST dispatch with a session-bound token and controlled request errors.
- Configurable endpoints and a separate UTF-8 browser runtime, per-input debounce, and ordered requests.
- Full-page, AJAX, and embedded examples with no database dependency.
- Optional AdminLTE shell with configurable navigation and footer.
- Composer metadata, tests, CI configuration, documentation, and MIT license.

# HIEQueryUI 0.2.0-rc.1

This release candidate provides the PHP component and listener core, session persistence, and a browser runtime for incremental updates.

It includes Button, Input, Checkbox, Container, Viewport, navigation, and an optional AdminLTE shell. Standalone examples demonstrate AJAX, full-page, and embedded use. The package requires PHP 8.2 or newer and is MIT licensed.

Changes from earlier copies include escaped text, explicit trusted HTML, POST event requests with session tokens, and a separate browser runtime. See the [migration guide](docs/migration.md) before updating an existing application.

The [changelog](CHANGELOG.md) lists subsequent additions, and the [roadmap](ROADMAP.md) covers planned components. Test commands and browser checks are described in [Running tests](docs/testing.md).
